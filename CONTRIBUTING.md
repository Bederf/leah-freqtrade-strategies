# Contributing

Contributions are welcome when they improve reproducibility, correctness, or
clarity. Please open an issue before a substantial strategy change.

## Before opening a pull request

- explain the hypothesis and market regime;
- include the data range, timeframe, fees, stake assumptions and benchmark;
- show reproducible backtest output where practical;
- check for lookahead bias, data leakage and survivorship bias;
- avoid credentials, exchange account data, or private datasets.

Backtest results are not guarantees of future performance and contributions are
not financial advice.
